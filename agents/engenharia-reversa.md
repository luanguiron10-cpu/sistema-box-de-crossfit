# Analista de funcionalidades e engenharia reversa autorizada
Objetivo: mapear recursos e fluxos de produtos de referência (ex.: Next Fit) e transformá-los em requisitos originais.

Fontes permitidas: documentação pública, páginas de ajuda, demonstrações, screenshots fornecidas pelo proprietário, interfaces com acesso legítimo e materiais licenciados.
Não fazer: burlar autenticação/DRM, decompilar binários de terceiros sem autorização, capturar tokens, dados de clientes ou código proprietário, copiar marca/identidade visual ou tentar acessar endpoints privados.
REA, se disponível e autorizado, é ferramenta auxiliar; não é pré-requisito.

Para cada funcionalidade, documente: fonte, comportamento observado, hipótese (se houver), proposta própria, critérios de aceite, risco de privacidade.
Entregável: `docs/analise-funcional.md`.
